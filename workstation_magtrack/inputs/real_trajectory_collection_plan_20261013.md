## 方案结论

网络输出采用 **hospital 原生传感器阵列坐标系中的磁铁参考中心位置**。主路线使用低高度 LM 锚点与机器人实际法兰位姿联合标定，估计板外参和工具偏移；精准手工测量杆倾斜、偏心与胶层厚度不再是采集前提。最终物理目标仍是磁铁几何中心，当前标签的中心和精度等级按磁辅助参考明确记录。固定变换假设装配刚性稳定，杆弯曲或滑动需要另外检查。

采集应包含五类记录：几何标定、时间同步、无目标背景、无磁铁的机械臂运动、有磁铁的目标轨迹。背景可以按小批次配对，几何标定按安装状态复用。不能在每条测试轨迹结束后，用磁定位结果重新对齐机器人轨迹。

先生成离线候选并检查完整路径；完成专用低高度联合标定及留出检查、三条联调后，再录制 60 条 pilot，检查 15–20 cm 的参考标签稳定性、干扰和可达性，最后依据学习曲线扩量。高处标签由冻结标定后的机器人反馈生成。独立计量作为后续绝对精度验证升级；本方案中的数量、速度和误差限是实施起点，验收依赖实测。

## 坐标系和标签定义

### 输出相对哪个中心

定义：

| 符号 | 含义 |
| --- | --- |
| S | hospital 配置中的传感器阵列坐标系 |
| B | 机器人基座坐标系 |
| F | 机器人法兰坐标系 |
| C | 当前标签使用的磁铁中心点；主路线为磁参考中心 Cref |
| M | 固定在载具上的参考坐标系，原点与当前标签中心一致 |
| K | 独立光学测量系统坐标系 |
| A | 磁铁附近的光学标记坐标系 |

第一版监督目标为 `p_S_Cref(t)`，单位为米。采用现有原生约定，板上方的目标处于负 z，参考高度 `h_ref = -z_ref`。20 cm 条件按传感器敏感平面计算；主路线下它是标定参考中心的高度，几何中心的实际绝对高度还取决于标定偏差。桌面、板外观表面和夹爪位置不能直接代替该高度。

现有配置为 8×8 个传感器，间距 50 mm，阵列跨度 350×350 mm。外观板约 400×400 mm，其几何中心相对阵列原点约有 10 mm 的 X 偏移。因此应使用配置原点，不能直接把 CAD 外观中心当作网络输出原点。[1]

不需要额外引入任意“世界坐标系”。但机器人反馈在 B 中，所以仍然需要测量 B 与 S 的关系。显示中的 swap/flip 只用于展示，不能代替物理坐标注册。坐标旋转应满足 `RᵀR = I`、`det(R) = +1`，并用不对称的板上标记检查轴向和传感器 ID。

### 真值指几何中心还是磁中心

最终位置目标为磁铁几何中心。当前无需精准装配计量的主路线，使用 **低高度 LM 定义的参考中心 Cref**：将低处磁锚点压缩成固定板外参和工具偏移，再由机器人反馈生成所有工作高度的标签。

LM 有效中心可能与几何中心有偏差。保存标签中心类型和参考来源；当前误差指标对 Cref 计算，独立升级后才能对经计量确认的几何中心给出绝对精度。每条高处轨迹的 LM/EKF 输出仅作为待评估方法，标签不采用其逐帧估计。

固定的参考中心偏移可以进入工具标定。若有效中心随姿态或工作条件变化，一个固定偏移就不够；须通过不同低高度、姿态子集的标定一致性检查发现问题。

第一版可以只监督 xyz。方向标签需要另外定义：

- 主路线可以用低处 LM 的有符号方向联合估计载具中的固定磁化轴；它属于磁辅助方向参考。
- 实体轴可由几何计量升级验证。磁化轴不能默认与杆轴或圆柱轴完全一致。
- 理想轴对称偶极子的轴向 roll 不可由磁场恢复。记录机器人完整姿态不代表网络可以辨识完整磁铁 6 自由度。

## 装配误差如何进入真值

### 用标定后的工具偏移构造标签

约定 `T_A_B` 把 B 中的坐标变换到 A 中。以下 C 表示所用标签中心：主路线采用 Cref，独立计量升级可采用几何中心。令 `r_F_C` 为该中心在法兰中的固定坐标，则：

```text
p_S_C(t)
  = R_S_B [p_B_F(t) + R_B_F(t) r_F_C] + t_S_B

具有完整实体姿态标定时：
T_S_M(t) = T_S_B T_B_F(t) T_F_M
```

杆倾斜、偏心和胶层厚度通过联合估计的 `r_F_Cref` 吸收。位置标签只需固定中心偏移；完整实体姿态需要额外信息，磁化轴可以单独从低处 LM 的方向一致性估计。

现有胶粘装配可以保持使用，先检查其刚性与稳定性。杆长和板位置只需粗量以初始化及核验路径间隙；精确参数由校准 pose 求出。多视角光学、接触测量或定位夹具保留为将来的几何中心独立验证方法。

优先以法兰 F 为稳定参考。若机器人仅提供实际 TCP 反馈，则：

```text
T_B_F(t) = T_B_TCP(t) inverse(T_F_TCP)
```

这里的 `T_F_TCP` 必须是控制器当前实际生效的 TCP 配置，不能使用脚本中的默认值。保存该配置和修改记录；采集期间变更 TCP 时必须划分新记录段。

### 为什么录完做一次刚体对齐不够

假设磁铁偏移标错了 `delta_r`，中心误差包含：

```text
delta_p_B(t) = R_B_F(t) delta_r
```

手腕旋转时，误差方向随之变化。一次固定的轨迹旋转和平移不能消掉这个误差。整条轨迹保持同一姿态时，偏移误差可能看起来只是平移，反而掩盖了问题。

因此主路线用专用低高度磁锚点和实际机器人位姿，同时标定板外参与工具偏移，再生成全部标签。需要多位置、绕至少两个不平行轴的旋转、足够姿态跨度以及可观测性检查；固定姿态采集会让工具平移与板平移难以分辨。

联合标定与训练评估轨迹分开记录，参数冻结后复用。该流程提供磁辅助参考，独立光学或几何计量可进一步验证其绝对偏差。

### 固定变换解决不了哪些误差

| 误差 | 处理方式 |
| --- | --- |
| 固定杆倾斜、偏心、胶层厚度 | 标定实际工具到磁铁中心的变换 |
| 固定磁铁倾斜 | 联合标定中心偏移；低处 LM 估计固定磁化轴，实体轴可另行计量 |
| 杆随姿态或加速度弯曲 | 重复低处检查、降低动态负载；需要定量核验时增加近磁铁独立标记 |
| 夹持滑动、松动、胶层蠕变 | 批次前后检查，发生变化后停止复用旧标定 |
| 机器人姿态相关的绝对位置误差 | 独立光学测量或其他计量核验 |
| 四块 PCB 拼接偏移、板弯曲 | 测各板定位基准与敏感平面的关系 |
| 磁铁、杆或周围金属改变实际磁场 | 做真实场残差与材料对照，不能用坐标对齐消除 |

## 真值获取路线

### 主路线 低高度 LM 与机器人联合标定

本路线适用于无法精准测量杆偏斜、胶层和磁铁偏心的现有装配。只需粗量杆长与板位置，用于初始化和路径间隙检查；固定磁参考中心的工具偏移由专用校准记录估计。以独立光学计量作为后续验证升级，不作为首轮采集的硬件前提。

#### 联合求解的参数

对低高度第 i 个静止 pose，记录：

- 机器人实际法兰位置 `a_i = p_B_F_i` 和旋转 `Q_i = R_B_F_i`。
- 原始磁场经固定背景扣除后的静止观测。
- 由 hospital LM 得到的传感器坐标系位置锚点 `y_i`。
- LM 收敛、多初值一致性、饱和、时间稳定性与可用通道信息。

联合估计三个量：

```text
R = R_S_B        机器人基座到阵列的旋转，3 个自由度
t = t_S_B        对应平移，3 个自由度
r = r_F_Cref     法兰到磁参考中心的固定偏移，3 个自由度

q_i(R, t, r) = R (a_i + Q_i r) + t

minimize over R in SO(3), t, r:
  sum_i robust_loss(
    (q_i - y_i)^T W_i (q_i - y_i)
  )
```

`W_i` 是锚点的权重或近似逆协方差。LM 的协方差可以辅助加权，但其小协方差不证明没有模型偏差。每个静止 pose 作为一个标定单位，避免驻留更久的 pose 获得不成比例的权重。

这个优化共 9 个几何未知量。旋转约束使用 SO(3)，采用多个合理初值检查收敛，保存雅可比的秩和按参数尺度归一化后的条件数。长度按米处理，固定尺度为 1；不使用自由缩放、逐条轨迹变换或每个 pose 的独立位置修正来隐藏标定问题。

此前的“先量出准确磁铁中心偏移”改为“通过磁锚点和实际法兰位姿联合估计偏移”。一次普通刚体轨迹对齐只有板外参，不能完成这里的工具偏移标定。

#### 校准 pose 如何安排

先在较保守的高度进行低速定位，粗量误差进入碰撞间隙。稳定后，可从名义约 6、8、10 cm 三个低高度开始筛选。当前配置磁铁直径 10 mm、高度 7 mm，磁矩强度为 0.114325 A·m²。[11] 这些配置值不能直接保证该高度的 LM 准确度。

高度筛选同时检查信噪比、最近传感器饱和、有限尺寸磁体带来的近场偏差、周围材料和 LM 多初值一致性。高度越低不一定越准确；选用误差稳定的低高度带。

一个起始 pose 集合：

1. xy 选中心与周围共 9 个点，范围约 ±100 mm，实际由可达性裁定。
2. 每个点安排约 3 个高度。
3. 每个位置安排 5 种法兰姿态：基准，以及绕两个不同局部轴的正负约 20° 倾斜。
4. 总计约 135 个 pose；不可行姿态重新规划或替换，并检查剩余集合的秩。
5. 全部运动到位后等待机械稳定；可先设置约 0.3–0.5 秒稳定段，再取约 0.5–1 秒有效观测，依据静止状态调整。
6. 保存每帧原始数据。静止段可以离线平均场值后运行 LM，或对逐帧 LM 做稳健汇总；保留两者结果，检查异常分支。

取静止段均值是降低锚点随机噪声，不是对目标场重新居中。背景仍使用目标进入之前的 10 秒固定均值。时间相关性会降低平均的收益，不能按帧数直接推算锚点精度。

至少需要两种不平行旋转轴。固定姿态时，`r` 与 `t` 的一部分完全混淆；只绕单一轴转动时，该轴方向的偏移仍可能不可辨识。多位置、多个高度帮助约束外参，并揭示只在单一高度成立的拟合。

理想构型的局部雅可比检查中，固定姿态的秩为 6/9，单轴旋转为 8/9，上述两轴组合为 9/9。这只是可辨识性示例，真实 pose 集合仍需重新检查，满秩不等于毫米级准确。

#### 拟合与留出检查

将 pose 按完整位置或姿态组分为约 80% 拟合、20% 留出，不能把同一驻留的相邻帧分别放入两组。留出位置和姿态可使用穿插的新点，避免只复测拟合点。

步骤：

1. 锁定当前传感器配置、磁矩强度、固定背景和 hospital LM 版本。
2. 在低高度逐 pose 求 LM 锚点，记录多初值结果；只按预先定义的观测质量规则筛选。
3. 用合格锚点与实际法兰 pose 求解共同的 `R,t,r`。
4. 在留出 pose 上比较机器人变换后的中心与低高度 LM 锚点。
5. 按位置、高度、手腕姿态分层检查残差，观察是否存在随旋转变化的系统偏差。
6. 独立重复一份校准记录，比较其参数，以及两组参数在目标工作区生成的位置差。
7. 分别用不同低高度子集拟合，再比较其对同一批 15–20 cm 机器人 pose 生成的参考标签，检查外推敏感性。

最后一步只比较标定结果，不使用 15–20 cm 磁场重拟合变换。若不同低高度子集会使高处标签相差数毫米，应先调查近场偏差、磁矩配置、机器人干扰、几何退化或夹具问题。

每次拆装重新估计几何参数，但磁矩、算法和质量阈值遵守冻结协议。测试安装的专用低高度标定记录与待评估轨迹分开保存，这是获取参考标签的测量流程，不是网络测试时的训练数据。

#### 方向与动态同步

LM 的有符号磁矩方向可用于估计法兰中的固定磁化轴：

```text
m_F_i = Q_i^T R^T m_S_LM_i
```

对单位方向做稳健汇总，并检查不同 pose 的一致性。该方向是磁辅助参考轴；不需要假定杆与磁铁同轴，也不提供轴向 roll 的可辨识性。只有位置任务时，可先不生成方向监督。

几何标定优先使用静止 pose，减少时间偏移与工具偏移互相混淆。几何冻结后，再做低高度的慢速往返动态校准，核验或估计残余时延。硬件同步优先；暂时无法实现时，低高度磁锚点与机器人运动可提供模型相关的时间参考，使用多方向、多速度、正反向记录检验一致性，单独保存时延不确定度。高处测试误差不参与选择时移。

#### 标定后如何生成真实轨迹标签

```text
低高度专用校准：
  原始磁场 -> LM 锚点
  实际机器人 pose + LM 锚点 -> 固定 R,t,r

任意工作高度的目标轨迹：
  实际机器人 pose + 固定 R,t,r
    -> p_S_Cref(t)

磁网络输入：
  该轨迹的磁观测、允许的历史与公开传感器配置
```

20 cm 标签由机器人实际反馈和冻结几何生成，不由该段高处 LM 输出生成。低处 LM 作为标定工具，网络仍有机会在高处超过 LM 的单帧或时序定位表现。机器人反馈继续仅用于标签和评估。

低高度标定原始磁场可以用于标定拟合；是否另用于网络训练必须按 session 和轨迹分组预先声明。盲测安装中的标定记录只用于测量参考构建，不用于网络微调或模型选择。

#### 参考真值的含义与验收

当前标签明确记为：

```text
reference_type: magnetic_assisted_robot_kinematic
reference_center: low_height_LM_effective_center
independent_absolute_validation: unavailable
```

字段名是未来元数据约定示例，不是已经实现的配置。

低处 LM 的随机误差可通过多 pose 的共同拟合降低；固定偏差可能进入 `R,t,r`。例如低处 LM 全体位置都偏高 2 mm，优化可能把该偏差写入板平移，留出残差仍然很小。因此留出残差、重复性和满秩主要证明一致性，不能单独给出真实绝对精度。

第一轮验收包括：几何满秩、多初值稳定、留出残差可解释、重复校准生成的目标工作区标签稳定、不同低高度子集没有明显冲突、动态同步与夹具状态一致。验收数值在 pilot 中按目标定位误差预算确定。Bootstrap 按 pose 或校准记录重采样，所得区间只覆盖已建模的随机变化，不能覆盖共同模型偏差。

这类标签适合真实数据训练、工程比较和低处标定到高处跟踪的研究。报告结果使用“磁辅助标定参考误差”或“相对机器人参考标签的位置误差”。完整真值不确定度尚未独立测出时，不能把较小的参考误差直接解释为磁铁几何中心的同等绝对误差。

若后续要证明几毫米级真实绝对精度或磁前向模型失配，可只对少量静态检查点增加独立验证，不需要全程光学录像。检查点应覆盖低处与 20 cm、中心与边缘、不同姿态；可采用经过敏感平面注册的非磁性定位夹具或独立计量设备。该升级验证磁标定偏差，不改变大规模机器人采集流程。

### 独立验证升级 机器人执行与光学真值

把轻量、非磁性、刚性的光学标记安装在磁铁载具附近；传感器板的固定载体上布置不对称参考标记。测量两条几何关系：

1. 板参考标记到 S 的关系。
2. 磁铁附近标记 A 到几何中心 C 的关系。

光学系统直接产生：

```text
p_S_C(t) = T_S_K T_K_A(t) [p_A_C; 1]
```

式中取齐次变换结果的前三维。机器人反馈用于执行、冗余检查和光学短暂失效诊断。

标记只贴在法兰上，无法观察法兰到磁铁之间的杆弯曲；应尽量靠近磁铁。优先考虑经标定和实测验证的双目全局快门、光学计量系统或其他满足误差预算的设备。普通 RGB-D 或单目 AprilTag 可以做流程原型，但不能仅凭分辨率、PnP 返回值或小重投影误差，宣称毫米级真值。

光学验收至少覆盖中心、边缘、不同高度和不同姿态，使用独立已知距离与三维检查点核验尺度、畸变和定位误差。动态轨迹还要核验曝光、运动模糊、帧率与时间同步。静态检查通过不代表快速运动标签同样准确。

若光学真值失效，保留原始记录和无效 mask。需要机器人替代标签时，应显式标为不同真值等级，不能无标记地混入主要独立评估。

### 独立验证升级 刚性标定夹具与机器人反馈

可以先采用机器人实际反馈生成参考标签，但需要独立核验精度。机械臂重复精度不等于其在整个工作区内的绝对位置精度。

建议制作可重复安装的非磁性磁铁载具，提供定位面、定心结构和锁定机构。优先使用载具控制磁铁位置，胶层承担固定功能。延长杆应兼顾刚度和远离机械臂磁干扰的距离，长度由实测决定。

一种可执行标定流程：

1. 用同一载具上的刚性探针做 pivot 标定。探针尖端置于固定窝点，改变法兰姿态，求解 `r_F_probe` 与固定窝点 `c_B`：
   `R_B_F_i r_F_probe + p_B_F_i = c_B`。[4]
2. 通过载具的实测几何，得到探针尖端到磁铁中心的偏移。pivot 只标出探针尖端，不能自动知道磁铁中心。
3. 在板固定载体上设置已知 S 坐标的基准点，用已标定探针测出对应 B 坐标，再求解 `T_S_B`。
4. 在未参与拟合的检查点上核验，覆盖不同高度和姿态。
5. 对至少一部分动态轨迹使用独立光学或其他计量设备，验证机器人标签和杆刚性。

pivot 起点可用约 20–30 个充分分散的姿态，并留出约 10 个检查姿态；板注册可用约 9–12 个分布在较大范围的基准点，再增加若干已知高度的检查点。数量不是精度保证，应检查拟合条件数、残差、留出误差和重复标定稳定性。

刚体注册数学上需要至少三个非共线对应点。工程上增加覆盖范围和抬高的检查点，便于发现高度零点、尺度与法向问题。板藏在桌下时，使用与板载体刚性相连、外部可接触的基准；桌面自身不能自动成为传感器平面。

若独立核验尚未满足精度预算，这些标签应称为“机器人运动学参考标签”。它们可用于工程训练，毫米级性能结论需要相应的真值证据。

### 板本身也要标定

现阶段先锁定 hospital CSV 的传感器 ID、名义位置和姿态，用于 LM 与联合标定。四块 PCB 的拼装误差不一定能由共同刚体变换吸收，校准残差应按通道与板分组检查。后续精度升级时核验：

- 每块 PCB 相对载体的位置、角度与固定方式。
- 传感器封装到实际敏感点的几何关系及其不确定度。
- 板间高度差、敏感平面到桌面的距离。
- 磁通道轴向、ID 排列、单位、增益与偏置校正版本。

外部标记到板载体、载体到各 PCB、PCB 到敏感点的关系应可追溯。每块 PCB 的装配差异不一定能被一个全板刚体变换吸收。

保留 nominal 配置与实测几何版本，不覆盖上游原件。几何数据属于传感器配置；外参、工具偏移和真值派生版本分别保存。

## 时间同步和动态标签

### 记录实际执行状态

机械臂期望轨迹用于计划，真值使用实际反馈。UR RTDE 的 `actual_TCP_pose` 是 `x,y,z,rx,ry,rz`，后三项为旋转向量，不能按欧拉角解读。同步记录控制器时间戳、实际关节角、速度和 TCP 配置。[2]

e-Series 的 RTDE 支持最高 500 Hz，但实际速率取决于机器人型号、控制器和配置，输出也可能跳帧。确认是 UR5 还是 UR5e，并根据实际时间戳验收，不假定所有帧等间隔。[2]

磁源按现有 100 Hz 设计采集，保存设备时间、每板时间、序号、有效位和主机 monotonic 接收时间。固件确认没有滑动平均，但仍应确认传感器转换时刻、内部滤波延迟以及时间戳是在采样还是发包时打上。

### 将设备时钟映射到同一时间轴

建议模型：

```text
t_robot = a * t_sensor + b
```

长记录要检查漂移，必要时按有依据的时间段拟合；光学时钟同样映射。

优先使用双方能带设备时间戳记录的公共硬件事件。是否可以让 Nucleo 与机器人采到同一触发，目前需要核实；只有主机上同时执行两条软件指令不够。光学同步可使用同一事件的灯光信号，但要考虑曝光时间。

暂时没有硬件触发时，保留设备和主机的全部时戳，用独立同步实验测量偏移范围、抖动和漂移，降低运动速度，使残余时间不确定度落在真值预算内。跨设备都使用主机接收时间不能自动消除串口缓存和网络延迟。

机器人与光学的时间关系可通过独立运动观测核验。磁采样同步优先使用采样时间戳和公共事件；主路线暂时缺少公共事件时，可以使用专用低高度往返记录估计模型相关的时延参考，保存其不确定度并在高处测试前冻结。不能通过“哪个时移让磁网络测试误差最低”决定标签时移。

### 在磁采样时刻生成标签

对机器人平移做时间插值，对姿态做正确的旋转插值，再变换到磁铁中心。旋转向量须先转换为旋转矩阵或四元数；公共四元数保存为 `wxyz`，不直接线性插值旋转向量。

要求：

- 记录插值两端时间和最大间隔。
- 超过间隔限、缺同步锚点、光学失效或机器人反馈异常时，标签无效。
- 不使用未经验证的长时外推补齐真值。
- 四块板异步时，保留各板采样时刻。可以给当前磁帧组定义统一参考时刻，同时保存各板相对时间差；若进行时间补偿，需明确算法和可用信息。
- 区分测量时刻、整组磁观测可用时刻、主机接收时刻和算法输出时刻。

离线生成标签可以使用前后两个真值样本；在线磁网络只能读取预测时刻已经可用的磁数据。测量时刻误差与“输出时刻的当前状态误差”是不同指标，后者应计入延迟或使用明确的预测任务。

### 误差预算

在速度 `0.1 m/s` 下，`5 ms` 时间错位产生约 `0.5 mm` 位置误差。长度 `0.30 m` 的杆遇到 `0.1°` 姿态误差，中心位置误差约为 `0.52 mm`。

磁铁中心速度为：

```text
v_B_C = v_B_F + omega_B × (R_B_F r_F_C)
```

所以“法兰位置不动”并不意味着磁铁中心不动；旋转引入的速度也进入同步预算。

磁辅助主路线先报告参考标签的重复性、留出一致性和标定敏感性，不把这些统计量直接当作绝对真值不确定度。后续若要判断几毫米级几何中心绝对误差，可将完整真值链的 P95 不确定度目标设为约 1 mm，通过独立核验决定能否达标。升级时按下表给各项分配预算：

| 项目 | 核验方式 |
| --- | --- |
| 板到机器人或光学外参 | 未参与拟合的三维检查点 |
| 标记或法兰到磁铁中心 | 载具尺寸、重复安装、不同姿态检查 |
| 动态形变和机器人误差 | 靠近磁铁的独立光学轨迹 |
| 时间偏移和抖动 | 独立同步事件、速度分层核验 |
| 光学尺度、畸变与动态误差 | 独立尺度与动态三维检查 |
| 板敏感平面和中心零点 | 机械基准到敏感点的实测关系 |

不能把多个系统性偏差直接用平方和开根号合并。只有独立、近似零均值的误差项才适合这类合成；最终以完整链的独立检查为准。

## 背景与校准记录如何配套

### 每个安装状态保存哪些记录

| 记录类型 | 是否有磁铁 | 用途 | 复用范围 |
| --- | --- | --- | --- |
| 低高度联合标定与留出检查 | 主路线有磁铁 | 板外参、工具偏移、磁参考中心与轴 | 安装状态保持稳定期间 |
| 时间同步 | 与目标磁场无关的独立事件 | 时钟映射、偏移、漂移 | 相同设备时钟连续段 |
| 静态空场 | 无目标，机械臂在规定起始状态 | 固定背景均值、噪声与漂移统计 | 当前背景批次 |
| 无磁铁机械臂运动 | 移除磁铁，保留载具或等质量非磁性替代物 | 动态机器人干扰、标签捷径对照 | 代表性轨迹和安装状态 |
| 有磁铁目标运动 | 有 | 实际训练和评估 | 绑定当前标定与背景 ID |
| 批次后空场与检查点 | 移除目标或到经验证的停车位 | 检查漂移、滑动和外参变化 | 当前批次质量报告 |

配套矫正记录包括 **低高度 LM 与机器人联合几何标定、专用动态同步核验、无磁铁运动对照**。它们分别解决工具偏移与板外参、时延、机器人磁干扰，按用途分段并保存。

每条目标轨迹必须关联背景和标定，但不要求每条都重新做完整标定，也不要求每条都录一份完全同长度的空场。发生拆装、板移动、TCP 配置变化、滑动或真值检查不通过时，重新标定并划分安装状态。

### 固定均值与较长原始背景并存

本项目既定协议是 **取最初 10 秒无目标观测的均值，此后固定相减**。[5]

一个批次的操作：

1. 磁铁移除，或放到已验证的停车位置。机械臂回到规定背景起始状态。
2. 每个 session 初始连续录制60–120秒有效无目标原始数据；后续每批至少30秒，条件允许时推荐60秒。首段兼作首批背景。按本批首10秒计算默认固定均值，记录有效帧数和质量状态。
3. 磁铁进入任务区，录制约 5–10 条目标轨迹。持续保存原始磁流，切段仅作为元数据。
4. 磁铁退出后，再录10–30秒空场，检查漂移。
5. 如背景变化超过预先设定的限值，未来批次重新建立背景。前一批的数据保留，并标记背景变化。

在 100 Hz 下，10 秒名义上约 1,000 帧；时间相关性会降低有效独立样本数。不能用批次后背景重算批次前均值，或对有磁铁轨迹逐段重新居中。背景检查阈值应在开发阶段依据空场变化和 20 cm 信号影响确定，测试前冻结。

较长背景和原始目标场完整保存，用于不扣均值、5/10/30秒背景上下文的后续配对比较。默认首10秒均值与上下文各自的起止时间、背景末端至目标开始的间隔均须保存，派生时冻结。上下文只使用目标开始前已经取得的观测；批次后背景不作为在线输入。背景不足的条件标明不可用，不用重复或填充伪造30秒观测。同一背景关联的目标轨迹按同组划分，不跨训练/评价角色。

“磁铁停得远”不自动等于无目标。需将停车状态与磁铁真正移除的记录比较，验证残余场在整个阵列上的影响，尤其是板边传感器。未通过时就用可拆载具移除磁铁，或扩大停车距离。

跨批次分别保存原始背景，不把所有日期的背景平均成一个通用均值。训练中也不能读取所属轨迹之后才采到的背景。

### 配对无磁铁运动怎么做

在移除磁铁后执行代表性的相同路径，实际关节轨迹也要记录。最好保留相同载具与近似质量，避免机械运动差异过大。

这种配对记录用于回答：

- 机器人和夹爪运动产生多大磁场变化？
- 其变化是否与目标位置高度相关？
- 固定背景相减后，20 cm 的目标信号是否被这些变化淹没？
- 同一磁铁位置、不同合法机器人姿态下，输入变化有多大？

两次执行不是逐点完全相同，不能按帧编号直接相减。离线分析须按实际时间和运动状态对齐，并报告差异。

“目标场减去对应的无磁铁运动场”可以作为理想化干扰移除诊断，但实际在线固定均值协议没有这条同时发生的参考场。其结果不能当作正常部署性能。

补充两个控制实验：

- 外部夹具固定磁铁，机械臂不带磁铁运动，直接测机器人动态干扰。
- 在可达条件允许时，以相同磁铁实体 pose 使用不同 IK 解；或固定中心、改变姿态并记录磁矩方向。UR 为 6 自由度，并非任意 pose 都有多个可行配置，应报告实际覆盖。

机器人关节角、TCP 位姿和命令路径只进入真值与评估元数据，不能输入本轮磁定位网络。磁铁刚性安装在机器人上时，这些变量会直接透露位置。

### 静态背景不等于目标相关失配

静态背景扣除可以消除稳定的加性场，却无法消除磁铁进入后在钢材中诱发的场变化。光学平台、桌面支架、杆、载具和夹爪的材料都需要实测核验。

建议先用非磁性载具与桌面，记录周围钢制物体的位置。对同一组冻结机器人参考 pose，比较环境材料变化前后的场；需要绝对位姿结论时再增加独立计量。真实实验中的目标相关失配、传感器误差、背景漂移和真值误差应分别诊断。

## 可达性和轨迹生成

### 从磁铁中心轨迹反求法兰轨迹

现有 hospital 轨迹生成器可以生成目标曲线，不能将输出的位置直接当作 UR 的 TCP 命令。[10]

给定磁铁实体期望位姿：

```text
T_B_F_desired(t)
  = T_B_S T_S_M_desired(t) inverse(T_F_M)
```

仅规划中心与法兰方向时：

```text
p_B_F_desired(t)
  = R_B_S p_S_C_desired(t) + t_B_S
    - R_B_F_desired(t) r_F_C
```

之后求 IK、选连续解、做完整路径检查。机器人实际反馈才用于最终标签。

特别是“磁铁中心固定、磁矩方向变化”：需要让法兰平移补偿工具偏移。直接在固定 TCP 位置旋转手腕，一般会让磁铁中心划弧线。

### 先制作实际可采工作区

在 S 中生成位置、姿态候选，得到“可行位置与姿态集合”，每个候选记录：

- 可用 IK 解与关节限位余量。
- 奇异性指标以及轨迹中是否存在解支跳变。
- 机械臂、夹爪、杆、磁铁、桌面和板载体的几何间隙。
- 整条轨迹的关节速度、加速度与控制器限制。
- 进入、退出和回停车位的完整路径。
- 参考中心是否位于目标高度范围；启用光学升级时还检查可见性。

先验证离散候选，再对完整连续路径做检查。可达点之间的连接不一定可达。最初的仿真可用于预筛，真实安装几何与低速核验决定是否可以执行。

不可行时重新生成轨迹或更换 IK 解，不对坐标逐点裁剪。裁剪会产生边界驻留、尖角和分布偏差。不可达区域保留在覆盖图中，论文与数据说明需说明工作区限制。

通过调整机器人与板的相对位置扩大覆盖时，形成新的安装状态并重新标定。机械臂可达性不足不应被误记为磁定位能力不足。

### 起始覆盖与运动类型

主工作区统一为 hospital 阵列坐标中的 `x,y ∈ [-0.13,0.13] m`，与当前模拟姿态池对应；实际可采区域由安装和 IK 决定。向 ±150–175 mm 边缘扩展时，单列为外推诊断，不挤占主工作区配额。这里以配置原点为基准，不能用外观板中心替代。

主高度范围为 10–20 cm，连续三维轨迹包含升降。计划约 60% 有效目标记录时间位于 15–20 cm，其余约 40% 位于 10–15 cm；15–16、16–17、17–18、18–19、19–20 cm 五箱目标各占总时间约 12%。按真实时间统计实际覆盖，不能仅看轨迹条数或重新修改标签凑配额。另在 15、16、17、18、19、20 cm 各设置静态驻留，跨记录改变 xy 和磁化方向。固定高度记录只作诊断，连续三维运动继续作为主任务。

| 类型 | 生成方式 | 重点检查 |
| --- | --- | --- |
| 静态网格与驻留 | 中心、边缘、角部，各高度和方向 | 标签偏差、低信噪比下的噪声 |
| 慢速连续平移 | 直线、圆、圆角矩形、平滑曲线 | 基本连续定位与同步 |
| 多速度平移 | 同一几何路线不同速度 | 延迟、速度依赖和滤波滞后 |
| 加减速与转向 | 平滑启动、停止、折返、方向变化 | 运动先验是否失效 |
| 中心固定的方向变化 | 补偿工具偏移，绕不同轴转动 | 磁矩方向与中心位置解耦 |
| 混合三维运动 | 高度、平移和方向同时变化 | 三维泛化与可达性 |
| 无磁铁配对运动 | 代表性同路径 | 机器人干扰和信息捷径 |
| 重装与跨日期轨迹 | 新标定、新背景、新参数 | 对安装和环境的泛化 |

磁矩方向可从覆盖较均匀的方向集合中采样，再筛除不可行姿态。避免一个高度始终对应一种姿态、一种速度或一种关节分支。批次内随机化轨迹顺序，并记录实际覆盖直方图。

### 速度分层与运动约束 v2

以下参数供生成候选使用，执行侧须结合真实机器人、TCP、杆长、负载及完整路径核验。pilot 核心只使用 V0–V3 与 W0–W3；V4 为通过核心 pilot 后另行开展的压力测试。未通过的档位保留为候选或未开放，不自动执行，也不把降速后的记录继续标成原档位。

| 线速度档位 | 磁铁中心标称线速度 | 角色 |
| --- | ---: | --- |
| V0 | 0 m/s | 静态、中心固定旋转 |
| V1 | 0.01 m/s（1 cm/s） | 慢速核心档 |
| V2 | 0.02 m/s（2 cm/s） | 常规核心档、平移联调起点 |
| V3 | 0.05 m/s（5 cm/s） | 核心较快档，低档联调通过后开放 |
| V4 | 0.10 m/s（10 cm/s） | 可选压力档，不计入60条核心 pilot |

| 方向变化档位 | 磁化轴标称方向变化率 | 角色 |
| --- | ---: | --- |
| W0 | 0 °/s | 静态、固定磁轴的平移和转弯 |
| W1 | 3 °/s | 旋转联调起点 |
| W2 | 10 °/s | 常规方向变化 |
| W3 | 20 °/s | 较快方向变化，低档通过后开放 |

方向变化围绕至少两种不平行轴安排；纯绕磁化轴自转不计入磁轴方向覆盖。记录磁化轴方向变化率和完整法兰角速度。固定中心旋转按工具偏移补偿法兰平移，实际中心残余运动照常记录和评价。

标称速度的定义必须随轨迹保存：固定磁轴的直线/转弯以巡航段速度为标称；混合与往返旋转以预定峰值为标称，包含平滑启停。全条均速、P95 和最大速度另外统计，不能把峰值当作均速。混合运动的 V/W 档位独立组合，避免慢平移总配慢旋转。

初始规划约束：

| 量 | 候选规划上限 | 检查口径 |
| --- | ---: | --- |
| 磁铁中心线加速度 | 0.05 m/s² | 总矢量模长，包含弯道向心项 |
| 磁铁中心线 jerk | 0.25 m/s³ | 总矢量模长，包含曲率变化 |
| 法兰角加速度 | 30 °/s² | 按连续 SO(3) 姿态曲线计算 |
| 法兰角 jerk | 150 °/s³ | 按连续姿态运动计算 |

采用满足上述约束的连续时间参数化，例如有界 jerk 的 S 曲线；方向变化使用连续旋转插值。平滑启停、折返和分段连接均须核验，不能瞬时切换速度或在尖角折返。匀速弯道还要满足 `v²κ ≤ a_max`，不能只检查切向加速度。机器人关节、法兰/TCP、夹爪/杆的约束另行检查；磁铁中心较慢不代表其他部件较慢。若约束冲突，重新规划几何或时间参数，并显式更新档位/时长。

时间误差采用初始诊断预算：`v_center,max × Δt ≤ 0.0005 m`；方向参考同时检查 `ω_axis,max × Δt ≤ 0.2°`。`Δt` 是独立同步实验给出的残余时间不确定度，包含未补偿的设备延迟与漂移；仅有 P95 时要注明概率口径。例：5 cm/s 对应线性预算10 ms，10 cm/s 对应5 ms，20 °/s 对应方向预算10 ms。这里只约束同步误差贡献，不代表完整标签达到这些精度。未满足时先改善同步或使用实测可接受的较低档，并如实报告缺失档位。

先执行 V0/W0、V2/W0 和 V0/W1 三条联调；同步和刚性核验后逐档开放 V3、W2、W3，V4 单独验收。所有数值在正式采集前保存为有版本的轨迹/机器配置；测试阶段不能按定位误差临时改变。

### 核心 pilot 数量与配对矩阵

两个 session 各30条，每类每 session 6条，共60条。目标有效记录约20 s/条，按真实时长统计；必要的进出场、背景及额外稳定段另计。若可行的完整配对路线需要不同记录长度，应保存实际时长和变更理由，不截断路径或伪造数据补足20 s。

| 类型 | 总条数 | V 档位分配 | W 档位分配 |
| --- | ---: | --- | --- |
| 静态 | 12 | V0：12 | W0：12 |
| 固定磁轴直线/升降 | 12 | V1/V2/V3：各4 | W0：12 |
| 固定磁轴转弯 | 12 | V1/V2/V3：各4 | W0：12 |
| 中心固定方向变化 | 12 | V0：12 | W1/W2/W3：各4 |
| 混合三维运动 | 12 | V1/V2/V3：各4 | W1/W2/W3：各4 |

固定磁轴直线/升降与转弯各采用4个几何路线族，每族以三档速度重参数化；每 session 两族。各族包含相同的预定几何比较段，允许更快记录重复经过；按共同几何段另作配对诊断，整条记录仍保留完整分母。正反方向、启停方式、xy 与高度在不同路线族间平衡。配对路线族始终放在同一数据角色中。

混合类先覆盖 V1–V3 × W1–W3 的9种组合，再补3条，使 V/W 各档边际数量均为4；例如额外 (V1,W1)、(V2,W3)、(V3,W2)。每 session 各线速度档、各方向变化档均为2条，具体分配由生成器检查。方向变化类四个路线族分别重参数化为三档，覆盖两种不平行旋转轴。

静态类每 session 在15、16、17、18、19、20 cm 各1条；另一 session 使用不同 xy/磁化方向。其余四类每类起点分为6条高区、6条低区；三种含平移的类别各至少3条高区路线包含连续高度变化，中心固定方向变化类保持中心高度固定。结合静态记录调整各段停留时间，实现上述按时间统计的60%高区与五箱覆盖目标。高区/低区标记只是生成配额，实际越过的全部高度照常计数，不强迫含平移的动态轨迹恒高。

以上为生成配额，不能把60条视为速度×高度×方向×环境的完整因子实验。实际缺口逐项报告；提高速度后的 IK/刚性问题与磁定位失败分别记账。400条主采集仍以五类各80条起步，各动态类别的三档边际数量分配26/27/27条，余数档位轮换；每 session 每类10条，三档按3/3/4条轮换。混合类在允许组合内平衡联合覆盖，而非绑定 V/W 同档。静态类总80条，在六个指定高度分配13/13/13/13/14/14条，余数高度可在预注册时轮换。正式分配在 pilot 后、查看盲测前冻结。

### 交给轨迹生成对话的输出合同

先交离线候选清单、三条联调和60条 pilot 的计划，不默认执行机械臂。每条至少包含协议版本、session/数据角色、轨迹族/配对 ID、seed、几何与磁轴曲线、V/W 档位、标称值定义、时间参数化、中心/法兰/TCP 的速度加速度约束、进入退出停车路径、IK与间隙结果、背景关联及未开放档位状态。

标定前只能生成中心空间中的候选和带粗测误差余量的预检；用于执行的法兰/TCP 计划须绑定验收后的 `R,t,r`、生效 TCP 和安装 ID。生成器记录拒绝/替换原因，不逐点裁剪，也不悄悄把5 cm/s改为2 cm/s。运动约束、数据配额、安装/机器设置在 Harness 中分别配置，不写进 domain 全局常量。

保留计划过程图：三维路径/磁轴、位置和高度随时间、线/角速度、加速度与 jerk、完整进出场；保留覆盖图：实际计划时间的速度×高度、方向×位置、类型×session、可达区域与拒绝原因。采集后用实际反馈另生成同口径图，报告标称/实际的偏差、停顿与未达巡航档位。图表标明“计划”或“实采”，不得用计划图替代执行证据。

### 重用生成器的范围

复用已有圆、线、平滑随机曲线的数学定义、参数和 seed。增加独立的机器人规划适配层，将 S 中的目标 pose 变为机器人可执行轨迹。

记录：

```text
生成器版本和 seed
原始中心与方向曲线
工具补偿后的法兰或 TCP 计划
可达性结果与执行命令
实际机器人反馈
参考标签、参考来源等级及其有效状态
```

计划与实际结果分别存储。不能把解析生成器输出当作实际真值，也不能通过修改真实标签让实际执行看起来与计划相同。

## 数据量和分阶段执行

### 首轮联调

进入未来真实验证阶段后，先采三条小记录：静态驻留、慢速平移、方向变化。逐条检查：

1. 64 个传感器 ID、单位与轴向。
2. S 中 xy 和负 z 约定，磁铁高度零点。
3. 法兰与 TCP 的差异，工具偏移补偿。
4. 背景是否在目标进入前取得。
5. 采样序号、缺帧、每板时差和设备时钟。
6. 低高度标定的一致性、方向变化时的装配稳定性，以及可用的独立检查。

三个检查通过后才扩大到 pilot。此阶段用于检验采集链，不能从几条轨迹计算研究结论。

### Pilot 与主采集

| 阶段 | 建议起点 | 有效记录规模 | 决策 |
| --- | --- | --- | --- |
| 静态空场与重复背景 | 每 session 初始60–120 s、每批至少30 s，累计先以约10 min起步 | 按实际完整时长与设备计数统计 | 噪声、背景上下文、漂移、停车位置验证 |
| 无磁铁机器人运动 | 先累计 5–10 min，覆盖代表性运动 | 约 30,000–60,000 帧组 | 动态干扰和捷径检查 |
| Pilot | 2 个 session，各 30 条，每条约 20 s | 60 条，20 min，约 120,000 帧组 | 真值、20 cm 信号、sim→real 诊断 |
| 主采集示例 | 8 个 session，各 50 条，每条约 15 s | 400 条，100 min，约 600,000 帧组 | 在通过 pilot 后开展 |
| 扩量 | 根据学习曲线增加完整 session | 以实际时长计数 | 只补仍有收益或覆盖不足的条件 |

主采集示例与早期的 300×20 s 方案同为 100 分钟有效目标记录；本方案增加 session 与重装覆盖。表中主采集独立于 pilot 计数，两者合计约 120 分钟、720,000 帧组。合格的 pilot 可以进入训练集，但其已被查看的结果不能成为最终盲测。

约10分钟空场是 pilot 起步预算，不是主采集的总时长上限；主采集按 session数、背景批次数及前后段长度另计。目标记录时长变化时，帧数与配额均用实际值重算。

这些是名义帧数，不是独立样本数。连续时序强相关；数据价值主要来自空间、方向、动态与安装状态覆盖。每条 15 秒记录须包含必要的历史 warm-up，评估时按预先定义的启动协议处理。

400 条不是充分性的保证。优先比较 25%、50%、100% 完整训练轨迹数量下的跨 session 学习曲线，检查高处误差与泛化是否继续改善。若固定偏差或干扰主导误差，先修正采集或标定，而不是继续堆帧。

实际现场时间另包含校准、背景、拆装、进出场和检查，不应将 100 分钟有效记录理解为 100 分钟完成实验。

### session 和数据切分

一个 session 对应连续设备时钟、明确安装状态和可追溯标定；内部可以有多个背景批次。跨日期或重新安装必须形成新 session 或安装 ID。

基础位置学习的 8 个主 session 可以按以下角色组织：

- 4 个用于训练，允许加入合格 pilot。
- 1 个用于模型选择与预处理超参数选择。
- 1 个预留给独立校准或后续开发。
- 2 个在流程冻结后盲测，包含跨日期与重装。

如果还要训练质量预测器并声称概率校准，需要另外明确“质量模型训练、模型选择、概率校准、盲测”各组。预留的一个 session 不应同时承担全部角色；数据量不足时增加完整 session，或缩小结论范围。

切分规则：

1. 按完整轨迹、完整背景记录和 session 分组，再切历史窗口。
2. 重复采集同一解析路径或近似参数的路线作为一个轨迹族分组，避免几何路线泄漏。
3. 固定背景 ID 与校准数据的复用关系随分组保存。
4. 测试安装可以录制专用低高度标定记录，构建该安装的机器人参考标签；标定记录与高处待评估轨迹分开。网络权重、磁参数、标定算法和阈值在测试前冻结，高处测试磁场不参与拟合外参或工具偏移。
5. 测试 session 的最初 10 秒无目标均值属于既定部署协议。额外无磁铁学习适配若使用，单独列为新的实验条件。
6. 看过并影响方案的 pilot 和开发测试不再称盲测。

## 采集工具需要补齐的部分

### 现有 hospital 工具不能直接承担监督采集

已检查的 hospital 版本存在两点：

- `magloc/tools/record_trajectories.py` 保存的是估计结果，并经过显示变换。[6] 低处 LM 锚点可以参与专用标定；正式标签须由同步实际机器人反馈和冻结标定生成，不能直接复用这个记录器的逐帧估计作为高处标签。
- `NucleoSerialSource` 上层使用 `latest_only=True`，消费不及时会跳过中间观测；实时显示适用的策略不适合原始训练流。[7]

可以复用已验证的协议解析和物理内核。原始记录应改为独立缓冲采集，磁流、机器人反馈、光学和显示推理解耦。显示只看最新帧，记录器保存全部收到的原始帧；队列溢出、串口断连和写入延迟必须显式报告。

“全部收到”仍不等于设备端没有丢包，需要设备序号或时间间隔核验。记录失败时保留已写入数据与失败状态，不将半条轨迹误标成完整采集。

### Harness 职责分离

| 目录或组件 | 职责 |
| --- | --- |
| `magtrack/domain/` | 帧、设备时间、轨迹 ID、标定记录、有效状态和单位约定；不包含路径、YAML 或设备 I/O |
| `configuration/` | 传感器、设备、数据、几何标定、同步、采集轨迹和机器配置分别解析；显式路径与 provenance |
| `sources/` | Nucleo 原始观测、机器人实际反馈、光学观测与离线观测窗口 |
| `algorithms/` | 纯几何标定、时钟拟合、插值、可达性数学和质量指标；不写日志、不直接驱动机器人 |
| `sinks/` | 原始流持久化、manifest、检查报告和派生标签输出 |
| `pipeline/` | 组装、生命周期、批次状态、同步各数据流；不隐藏标定数学 |
| `cli/` | 薄入口与明确采集模式 |
| 独立采集执行工具 | 经过路径核验后执行机械臂运动；不由离线训练或评估隐式触发 |

训练监督使用独立 target 字典，机器人和光学信息不能进入磁模型的 forward 输入。模型只使用部署时实际可见的磁场、时间、mask 和公开传感器几何；新增可观测温度等输入时，各基线采用相同信息。

代码实现时应先验证协议、时间、标签和数据泄漏契约，再接真实采集。本文只规定接口与采集流程，不修改 runtime、已有模型或正在运行的实验。

## 质量检查与评估

### 每个批次的验收

批次开始前确认安装 ID、TCP、标定版本、板 ID 和同步有效期。做若干未用于拟合的低高度 LM 检查 pose，结束后复测并报告参考一致性。启用光学升级时，遮挡段记录为无效，不用长时间外推制造连续标签。

质量报告至少包含：

- 100 Hz 实际采样间隔分布、缺帧率、板间时间差与缓冲异常。
- 机器人与光学的实际帧间隔，以及标签插值最大间隔。
- 外参和工具偏移留出误差、重复安装差异。
- 主路线的参考重复性、低高度子集敏感性与动态同步结果；独立升级时增加完整真值链核验。
- 背景前后变化、机器人无磁铁运动幅度、传感器饱和和坏通道。
- 实际高度、xy、方向、速度、加速度及可达区域覆盖。
- 每种无效原因的数量、持续时间和轨迹 ID。

缺帧、标定变化和真值失效可按预先定义的规则划为无效数据。弱信号、较大定位误差和真实干扰属于待评估现象，不能因模型失败而删除。

### 评估指标

同时比较经过正确几何、磁参数和噪声适配的 LM/EKF 类方法、当前 MLP，以及同信息同数据的强时序学习基线。输入历史、背景协议、传感器校正和测试记录保持一致。

位置指标至少包括：

- 平均欧氏误差 MEE、P50、P95 和分轴 bias。
- 误差超过 5 mm、10 mm 的比例。这两档是报告刻度，不预设为已达成目标。
- 高度分层，单独报告 20 cm、多方向与动态结果。
- 速度、旋转、中心/边缘、跨日期和重装分层。
- 失跟率、连续失跟时长、恢复时间和实际输出延迟。
- 每条轨迹和每个 session 的结果；置信区间按轨迹或 session 重采样，避免把相邻帧当独立样本。

主路线报告相对磁辅助机器人参考的位置误差，同时报告标定重复性与敏感性；尚未测出的绝对参考偏差明确标记为未知。独立升级后再将真值不确定度与几何中心定位误差一起报告。如果参考的不确定度与算法差异处于同一量级，结果不能可靠区分两者。

### 真实数据如何检验物理模型失配

固定当前参考位置和方向后，可以对留出实测场计算一致性残差：

```text
residual_i(t)
  = measured_field_i(t) - fixed_background_i
    - dipole_field_i(reference_pose(t), calibrated_moment)
```

磁矩参数、传感器增益或有效中心需要估计时，使用独立校准数据，冻结后在留出目标轨迹上检查。方向尚不可信时，先用固定姿态实验标定磁矩，并报告方向不确定度。

分析残差是否随高度、方向、机器人关节、桌面材料和时间变化。与空场及无磁铁运动记录比较，判断它来自：

1. 传感器噪声或背景漂移。
2. 机器人或夹爪动态干扰。
3. 传感器几何、轴向或增益误差。
4. 磁体有限尺寸、磁化不均匀或周围材料导致的目标相关失配。
5. 真值、夹具形变或时间误差。

主路线的位置和方向经过低处磁模型标定，该残差仍包含磁标定的共同偏差，只能用于留出一致性和失配线索分析。独立计量升级后的残差才更适合检验绝对物理失配。理想偶极子仿真加真实空场噪声同样不能直接证明真实目标相关失配；任何路线下，残差大都需要区分背景、标签与物理来源。

## 未来真实验证的实施顺序和扩量条件

| 步骤 | 执行动作 | 进入下一步的条件 |
| --- | --- | --- |
| 安装定型 | 固定板与现有刚性装配，粗量杆长和板位置；确定背景停车方式 | 装配稳定，路径间隙考虑粗量误差 |
| 低高度联合标定 | 多位置、多高度、多轴姿态，LM 与实际法兰联合求 R/t/r | 满秩、留出与重复一致性通过，参考等级明确 |
| 时间与记录器 | 核验设备时钟、同步、原始流和缺帧审计 | 100 Hz 数据可追溯，动态时间误差可量化 |
| 背景与干扰 | 静态空场、停车验证、无磁铁运动 | 能区分目标场与环境/机器人影响 |
| 三条联调 | 静态、慢平移、方向变化 | 单位、坐标、工具补偿和标签一致 |
| Pilot | 两个 session 共 60 条，按 v2 速度/方向矩阵 | 15–20 cm参考标签稳定性可量化，速度实际覆盖、可达与干扰有结论 |
| 主采集 | 冻结流程后分 session 采集 | 按学习曲线和覆盖缺口增加数据 |
| 盲测 | 新日期、重装、新轨迹与新背景 | 模型、阈值和预处理冻结后执行 |

进入未来真实验证阶段后的现场批次执行清单：

1. 确认装配、标定、TCP 和环境记录。
2. 保存设备启动信息，建立或检查同步映射。
3. 做真值检查 pose。
4. session初始录60–120秒、后续每批至少30秒无目标原始背景；默认均值取本批首10秒。
5. 执行已核验的 5–10 条轨迹，持续记录全部原始流。
6. 录制批次后背景和真值检查 pose。
7. 生成质量报告，标记异常，决定继续复用标定或重新安装标定。
8. 将完整 session 归入预定数据角色，生成派生标签版本。

未来真实验证阶段优先完成 20 cm 的真实证据链。若机器人静止时已有可信精度，运动后明显退化，先处理同步、动态干扰或形变；若同一 pose 在不同安装中有稳定偏差，先检查几何和材料；若参考标签一致性与干扰控制通过、学习曲线仍有明显空间，再扩大数据和网络；绝对精度与物理失配的强结论增加独立检查支持。

SR 的相机标签、独立无目标校准和环境分组值得借鉴，但其公开代码中最近标签匹配的时间容差、阵列形状、磁体和环境不能直接成为本板的精度保证。[8] 新网络或大量数据的收益，必须在本方案约束下由真实留出结果证明。
